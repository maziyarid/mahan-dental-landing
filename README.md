# Mahan Dental landing page

Google Ads landing page (React + Vite + Tailwind v4, RTL, Vazirmatn).

- `npm install && npm run dev`
- Set `VITE_LEAD_ENDPOINT` to the CRM/webhook URL that should receive leads.
- Add `public/brand-icon.png`, `public/wordmark.webp`, `public/favicon.png` (brand assets).
- A GTM `generate_lead` dataLayer event fires on successful submit.
